# 历史方案导航

原有编号文档已迁移，按旧路径或计划编号查找请使用[历史文档索引](../docs/reference/legacy-plans.md)。本目录仅保留导航，不新增方案，也不维护事项状态。

- [项目路线图](../docs/ROADMAP.md)：当前事项状态。
- [活动方案](../docs/plans/active/)：尚未结束的方案。
- [归档方案](../docs/plans/completed/)：已结束或退出当前执行入口的历史方案；归档不代表全部实现。
- [历史参考](../docs/reference/history/)：旧协议、技能样本和行为快照，不作为当前实现真源。

旧的单文件 URL 不提供自动重定向；文件沿革可通过 Git 历史追溯。
